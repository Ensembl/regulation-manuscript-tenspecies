## Experiments analysis

This folder contains the [metadataProcessing.Rmd](./scripts/metadataProcessing.Rmd) script
used for:

- Basic exploration of the number of epigenomic experiments processed
with the Ensembl Regulation [primary analysis pipeline](https://regulation.ensembl.org/help/primary_processing)
and released in [Ensembl 114](https://ftp.ensembl.org/pub/release-114/regulation/).

- Generating the Figure 2 of the manuscript.
