## Experiments analysis

This folder contains the [metadataProcessing.Rmd](./scripts/metadataProcessing.Rmd) script
used for:

- Exploration of the number of epigenomic experiments processed
by the Ensembl Regulation [primary analysis pipeline](https://regulation.ensembl.org/114/help/primary_processing)
and released in [Ensembl 114](https://ftp.ensembl.org/pub/release-114/regulation/).

- Generating Figure 1a of the manuscript.
