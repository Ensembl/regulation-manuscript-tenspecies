# Figures 2-5

This directory contains scripts and notebooks to generate Figures 2-5 of the associated manuscript.

Python requirements are listed in pyproject.toml.

## Notebooks

The `notebooks` directory contains Jupyter notebooks for Figures 2, 5a and Supplementary Figure 3.

- Figure 2 and Supplementary Figure 3: [species_stats.ipynb](notebooks/species_stats.ipynb)
- Figure 5a: [tissue-specific_features_pig.ipynb](notebooks/tissue-specific_features_pig.ipynb)

## Track generation

Tracks for Figures 3, 4, 5b and Supplementary Figure 2 are created in the `track_generation` folder.

Run the following scripts from in the `track_generation` folder:

- Figure 3 and Supplementary Figure 2: `./pygenome_king.sh`
- Figure 4: `./pygenome_myh7.sh`
- Figure 5b: `./pygenome_pig.sh`
